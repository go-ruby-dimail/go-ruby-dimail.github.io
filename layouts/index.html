go-ruby-dimail is the pure-Go, Ruby-runtime-independent core of the Ruby dimail gem: a client for the Dimail API, the mail-hosting management API of the French government's La Suite numérique platform. It is a thin, reflective adapter over the typed client in go-dimail: a Session exposes every one of the client's 91 operations through a single dynamic entry point that maps a Ruby-style snake_case operationId to the Go method, coerces the arguments (Ruby Hashes become request structs), and normalises the result into Ruby data. That uniform surface is what an rbgo method_missing binding drives — but nothing here depends on the Ruby runtime, so it is equally usable as a standalone Go library. 100% coverage, CI green across 6 arches.

A sibling of go-ruby-regexp and the go-ruby-* stdlib/gem family: the interpreter-independent core of a Ruby library in pure Go, cgo disabled, so it cross-compiles and embeds anywhere. The typed transport, models and errors live in go-dimail (generated from the API's OpenAPI document); this repo is the Ruby-idiomatic, Hash-returning adapter that github.com/go-embedded-ruby binds.
